# Курсовая работа по дискретной математике

## Системные требования для сборки

1. Операционная система
- **Windows 10/11** (64-bit)
- **Linux** (Ubuntu 20.04+, Debian 11+, Fedora 34+, CentOS 8+)
- **macOS** 10.15 (Catalina) или новее

2. Компилятор C++ с поддержкой C++17. Минимальные версии:
- **GCC 9+ или 11+** 
- **Clang 10+**
- **MSVC (Visual Studio) 2019** (и младше)
3. CMake версии **3.20+**

## Как приступить к работе:

1. Открыть репозиторий-шаблон https://github.com/dismath-coursework/calculator-template
2. Нажать зеленую кнопку **Use this template** в правом верхнем углу, выбрать **Create a new repository**.

3. Заполнить форму создания репозитория:
    1) Поле **Owner** - организация `dismath-coursework`
    2) Поле **Repository name** в формате `номер группы_Фамилия-Имя` (например, для группы 5130201/30101 - `30101_Martynenko-Anna`)
    3) Поле **Visibility** обязательно поставить `Private`
4. Нажать **Create repository from template**

5. Клонировать репозиторий на свою машину
6. в .github/workflows/test.yml вписать свой алфавит, максимальное и минимальное возможное значение в `jobs: test-all: - name: Run hidden test suite with: alphabet; minimum; maximum`
7. Изменить свой CMakeLists.txt, если необходимо добавить файлы в сборку
8. Keep calm and enjoy coding :)


## Структура репозитория студента
```
30101_Martynenko-Anna/
├── CMakeLists.txt              # Файл сборки проекта
├── src/                        # Реализация калькулятора
│   ├── BigCalculator.h         # Заголовочный файл (объявления методов)
│   └── BigCalculator.cpp       # Реализация всех методов
├── app/                        # Точка входа в программу
│   └── main.cpp                # Функция main() - запуск калькулятора
└── .github/
    └── workflows/
        └── test.yml            # Конфигурация GitHub Actions 
```

### Что где изменять

| Файл/Папка | Назначение |
|:---|:---|
| **`CMakeLists.txt`** | Если добавляются файлы `.cpp`, которые вы добавили, нужно прописать их в скрипт сборки |
| **`src/BigCalculator.h`** | Публичный интерфейс класса, объявляются методы `add`, `subtract`, `multiply`, `division`, `pow`, `gcd`, `lcm` |
| **`src/BigCalculator.cpp`** | **Здесь нужно писать реализацию функций** |
| **`app/main.cpp`** | Файл для реализации взаимодействия пользователя с программой |
| **`.github/workflows/test.yml`** | Конфигурация CI/CD. Нужно указать свои алфавит, минимум и максимум для передачу в автотесты |

## Как отправить на проверку и посмотреть результаты
1. **После ручного тестирования** закоммитьте свое решение и запушьте **в свой репозиторий**
2. Результаты можно посмотреть во вкладке **Actions** своего репозитория
3. Необходимый минимум - все пройденные тесты по операциям `add, subtract, multiply, division`
4. Приветствуются бонусные операции!

## Ограничения
- Автоматические проверки призваны помочь провалидировать финальные результаты, а не заменить ручное тестирование.
- Всего доступно 21 автоматическая проверка (первый коммит при создании репозитория + ваши 20 попыток). Используйте их с умом!
- После дедлайна (будет указан позднее, предварительно - дата сдачи курсовой на сессии) автоматические проверки будут недоступны.
